## 🧩 Lesson 1: How Big Is a Network?

### Foundations
1. [Network Size](01-network-size.md)  
   → Defines network scale by number of users (nodes) and geographical coverage.

2. [Topologies Overview](02-topologies-overview.md)  
   → Introduces LAN, MAN, and WAN as the three main topology classes.

3. [Network Lines and Channels](03-network-lines-and-channels.md)  
   → Explains private vs. shared communication channels.

4. [System Types](04-system-types.md)  
   → Covers symmetrical (peer-to-peer) vs. asymmetrical (client–server) communication models.

5. [Signal Strength and Hops](05-signal-strength-and-hops.md)  
   → Describes why signals weaken and how repeaters/hops extend range.

---

### LAN Topologies
6. [LAN Topologies (Overview)](06-lan-topologies.md)  
   → Summary of how LANs can be structured physically or logically.

7. [Bus Topology](07-bus-topology.md)  
   → Linear shared cable system; collisions and multiplexing methods explained.

8. [Star Topology](08-star-topology.md)  
   → Central hub/switch connection with private links per node.

9. [Ring Topology](09-ring-topology.md)  
   → Circular data flow, token passing, and MAU enhancement.

10. [Mesh Topology](10-mesh-topology.md)  
   → Fully connected design; redundant, costly, and complex.

---

### WAN
11. [WAN Overview](11-wan-overview.md)  
   → Describes WAN as a hybrid network connecting multiple LANs and MANs over wide distances.
